# Same Campus, Unequal Beginnings

Digital Humanities project prototype examining how spending power, prior exposure and regional context relate to participation, bonding and belonging in college social life.

## Live site
Deploy this repository directly to Vercel. `index.html` is in the repository root, so no build command is required.

## Project files
See the `project-files/` folder for the report framework PDF, Excel workbook, Gephi CSVs, questionnaire and deployment notes.

> The bundled 200-row dataset is synthetic pilot data for demonstrating the research workflow. It is not presented as real survey responses.
